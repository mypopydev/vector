# 翻译风格指南

翻译任何一章前，先读本文件 + `术语表.md` + `译名表-人名.md`，并翻一遍样本章（`cn-book/1.序言.md`、`cn-book/2.第1章-代数的解放.md`）对齐语感。

## 一、忠实度（硬要求）

1. **逐段翻译**：`en/` 里的一段 = 译文的一段。不合并、不拆分、不跳段、不概括、不扩写。原书的一段往往很长，译文可以拆成两个中文句子，但仍在同一个段落里。
2. **不删减**：包括作者的自问自答、口语化的插入语、破折号后的补充。原书的“碎碎念”正是它的风格。
3. **不添油**：不要为了通顺加入原文没有的解释、评价或背景知识。确需补充的（如译名说明）放在括号或脚注里，并标注“译者注”。
4. **保留语气**：作者用第一人称“I”→ 译“我”；设问句保留设问；惊叹句保留惊叹。

## 二、术语与人名

5. **术语**首次出现写“中文（English）”，例如“四元数（quaternion）”；同章第二次起只用中文。译名一律以 `术语表.md` 为准；遇到表中没有的术语，**先补进术语表再继续译**。
6. **人名**首次出现写“中文名（English Full Name）”，例如“威廉·罗恩·哈密顿（William Rowan Hamilton）”；其后只用“哈密顿”。文献注释里的作者名保留英文原文。
7. **书名、期刊名、论文题名**保留英文原文（可加中文译名），例如《*Treatise on Electricity and Magnetism*》（《电磁通论》）。

## 三、公式与符号

8. **公式原样搬运**：`$…$`、`$$…$$` 里的内容一个字符都不改，包括变量名、希腊字母命令、`\boldsymbol{}`。只翻译公式前后的文字。
9. **公式编号**保留：原文公式后的 `(1)`、`(2)` 照写；正文里“using (1)”“equations (2)”也要译出（如“利用式 (1)”“式 (2) 这组方程”）。
10. **行内数学**如 `*x*^**2**^`（x 的平方）译文中保持 Markdown 上标写法，不要改成 x²（避免字体缺字形）。

## 四、版面元素

11. **图**：图片行原样保留 `![](images/figN_M.jpg){width="50%"}`，只翻译 `[...]` 里的图注文字。**图注里不要写“图 N.M”编号** —— LaTeX 会自动按章编号；但要核对原文编号（FIGURE 1.1 → 图 1.1），若顺序对不上，在译文中保留原文编号并加译者注。
12. **知识框**（`::: {.infobox}` … `:::`）：框标题译为中文，保留加粗。
13. **引文**（`>` 开头的行）：整段译出，保留引用格式。
14. **分隔符** `• • •`：原样保留。
15. **脚注**：正文里的 `[^ch01n1]` 原样保留；定义行 `[^ch01n1]: 译文` 放在**本章文件末尾**，编号不改。
16. **交叉引用**：`chapter 4` → “第 4 章”，`chap. 2` → “第 2 章”，`figure 9.3` / `fig. 0.2` → “图 9.3”/“图 0.2”，`endnote 5` → “尾注 5”。
17. **分页标记** `<!--p123-->`：原样保留在原位置（构建时会变成页边的原版页码）。

## 五、中文行文

18. **长拆短，但不改顺序**：英文的嵌套定语从句拆成中文短句，尽量保持信息出现的先后顺序。
19. **标点**：中文全角标点；书名号《》用于书籍；引号统一用弯引号，外层“” 、引文内部的再引一层用‘’；**不要使用直角引号「」『’**；并列成分之间用顿号。
20. **英文标点不转写**：破折号 —— 保留；连字符用于复合词（3-D）保留。
21. **度量与编号**：`3-D`、`4-D`、`2 × 3`、`35 mph` 等保留原写法，必要时加中文说明。
22. **数字**：年代、页码、公式编号用阿拉伯数字；“four thousand years”这类约数译“四千年”。

## 六、禁止事项

- 禁止把 `vector` 译成“矢量”（全书统一“向量”）。
- 禁止在译文里残留大段未翻译的英文（技术术语、人名、书名、公式除外）。
- 禁止为了让句子“好看”而删掉原文的限定语（perhaps、arguably、seemingly 等恰恰是作者的分寸感）。
- 禁止改写脚注编号、图片文件名、`<!--p…-->` 标记。
