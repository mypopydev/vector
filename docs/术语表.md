# 术语表

**本表是全书的硬约束。** 翻译任何一章前先查本表；发现新术语先补表再译；表中已有译名不得另起炉灶。

## 译名总原则

1. **vector 全书统一译“向量”**，不译“矢量”。本书书名即《向量》，且叙事横跨数学与物理两界，混用两个译名会让读者误以为是两个概念。涉及麦克斯韦电磁理论时同样作“向量场”（vector field）、“向量分析”（vector analysis）。
2. 术语**首次出现**时写作“中文（English）”，例如“四元数（quaternion）”“平行移动（parallel transport）”；同一章内第二次起只用中文。
3. 公式中的符号一律保留原文，不做本地化改写。
